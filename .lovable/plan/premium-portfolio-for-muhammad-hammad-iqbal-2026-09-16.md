# Premium Portfolio for Muhammad Hammad Iqbal

## Goal
Build a polished, one-page personal portfolio that presents Muhammad as an SEO and digital marketing specialist with a strong frontend background, using only the supplied facts and claims.

## Experience
- Create a sticky floating navigation with smooth section links and an accessible mobile menu.
- Build a strong opening section with concise positioning, clear actions, and a custom analytics/code visual rather than stock photography.
- Present truthful stats, biography and contact details in a compact, recruiter-friendly format.
- Add services, grouped skills, SEO process, project case studies, work experience, education, and “Why Work With Me?” sections.
- Omit fake testimonials; include only a restrained note that the professional client portfolio is being built.
- Finish with a contact form, direct contact options, and a minimal footer.

## Visual Direction
- Near-black navy foundation with electric violet as the main accent and restrained cyan highlights.
- Manrope typography, strong hierarchy, rounded 18–24px surfaces, pill controls, thin luminous borders, and subtle glass effects.
- Abstract search-performance visualization made from lightweight interface elements, charts, and code cues.
- Gentle reveal, hover, glow, and floating motion with reduced-motion support.
- Carefully adapted layouts for desktop, tablet, and mobile without horizontal overflow.

## Technical Details
- Keep the portfolio at `/` as a semantic single-page experience with section anchors.
- Split the interface into reusable portfolio components and shared data structures.
- Make project, email, phone, LinkedIn, and navigation links functional.
- Make the contact form open a prefilled email draft so it works without inventing a storage or email service.
- Add route-specific title, description, Open Graph, Twitter metadata, structured data, and a custom favicon.
- Validate rendering and interactions at desktop and mobile sizes, including menu, form, links, focus states, and reduced-motion behavior.
